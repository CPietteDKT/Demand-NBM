## Purpose

Assess SAP's standard capabilities for the proposed Wholesale commitment flow using contracts and Scheduling Agreements, then document process fit and gaps. The proposal is exploratory and is not an approved target process.

## Scope boundary

This initiative is separate from the Business [Wholesale Demand & Inventory initiative](../wholesale-demand-inventory/README.md), which covers planning inputs and the in-season PO-flag approach. No dependency or combined solution is assumed.
