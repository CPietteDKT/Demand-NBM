# Glossary

> Entries marked *(to confirm)* are interpretations not stated explicitly in source documents.

| Term | Definition |
|---|---|
| **BP** | Business Plan — 3-year commercial trajectory (Y+3), at family level. |
| **CPD** | Price-related lever managed by ZMP/ZDM alongside purchase price and markup *(exact expansion to confirm)*. |
| **DSI** | Stock coverage indicator used as result KPI *(expansion to confirm, e.g. Days of Stock Inventory)*. |
| **DTB** | Engagement/team score used in ZDM KPIs *(expansion to confirm)*. |
| **EOL** | End of Life (product). |
| **FG** | Finished Goods. |
| **Implantation** | Initial allocation of products into the store network. |
| **IQ** | Store stock parameter defined during selection within the merchandising framework *(expansion to confirm)*. |
| **MRP** | Material Requirements Planning — calculates the order level needed to sustain demand. |
| **PQZD** | Tactical demand planning indicator *(expansion to confirm)*. |
| **PRMP** | Purchase price lever in the Supply P&L *(expansion to confirm, likely weighted average cost price)*. |
| **RFQ** | Request for Quotation — pre-season phase with suppliers. |
| **S&OP** | Sales & Operations Planning — mid/long-term alignment of demand, supply and finance. |
| **S&OE** | Sales & Operations Execution — short-term alignment and execution. |
| **SSV** | Product validating next-season Sales & Purchase forecasts *(expansion to confirm)*. |
| **Stock Norm** | Target inventory level during the season. |
| **Super-model** | Product aggregation level used for tactical forecasting. |
| **TOP/FLOP** | In-season decisions on over/under-performing products. |
| **UOM** | Unit of Measure — logistics parameter defined at base camp level. |
| **ZDM** | Zone Demand Manager. |
| **ZDP** | Zone Dispatch Planner *(to confirm)* — defines dispatch tactics. |
| **ZMM** | Zone Merchandise Planner Manager. |
| **ZMP** | Zone Merchandise Planner. |
| **Base camp** | Central / global perimeter (as opposed to zone or country). |
| **Supply Zone** | Geographic supply perimeter managed by a ZDM. |
